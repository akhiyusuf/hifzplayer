# Product notes (living)

Short notes from product direction. Not a shipping checklist — keep these in mind while doing Steps A–D and later work.

## Focus belongs on the mushaf half

Activating Focus only through sidebar / player settings feels difficult and stressful.

Word Reps, Masked, and Relay should be reachable **on the mushaf page itself** (the reading half), matching the “practise on the page” promise:

- **Word Reps** — word-level controls on the ayah (tap / pin / underline range)
- **Masked** — cover / peek on the same ayah block
- **Relay** — turn state on the ayah (underline / chips for whose stretch)

Settings can stay as a secondary home. Discoverability should not depend on the gear sheet.

## Coming later (do not build now)

- **Mutashabihat** — near-twin / similar wording support for hifz
- **Spaced repetition + active recall** — practice scheduling and memory checks
